# Joining a Batch (before buying, and joining late)

## JB-1 · Checking a batch before joining: details, timetable and demo lectures
Source: official — https://www.pw.live/teaching/exams/how-can-you-access-demo-lectures-and-batch-details-before-enrolling

Every batch has a batch page in the PW app and on pw.live that can be checked before buying. It shows the subjects included, the teachers for each subject, the batch validity (how long access lasts), and the course features, such as live classes, recorded lectures, study material, practice questions and tests. Many batches also have free demo lectures that can be watched on the batch page before enrolling. The class schedule and timetable are posted in the batch's announcements; if the timetable is not visible yet, PW advises waiting, because it is updated there. Demo lecture videos cannot be shared over WhatsApp, but the support team can send the batch link so the student can open the batch page directly. Because online batches are non-refundable once bought (RF-1), students should check these details and PW's free content (BA-5) before paying. For help choosing between batches, a counsellor can advise (CT-2).

## JB-2 · Joining a batch that has already started
Source: assumed for this prototype (PW does not publish a late-joining policy); the batch page's course features and validity are official — https://www.pw.live/teaching/exams/how-can-you-access-demo-lectures-and-batch-details-before-enrolling

Many online batches can still be bought after classes have begun. Before joining a running batch, the student should check two things on the batch page. First, the course features: if recorded lectures are included, classes already held can be watched in the app under Study > My Batches, and recordings of new live classes are added after each class. Second, the validity: it is the same end date for everyone in the batch, often tied to the target exam, so joining late means less time with the batch, not a later end date (BA-2). Joining late does not change the price or the usual rules: online batches are non-refundable (RF-1), and a batch bought by mistake can be changed to another batch of the same amount within 10 days of purchase (RF-2). A student who would rather start with a newer or upcoming batch can ask a counsellor which one fits (CT-2). Validity is not extended to make up for joining late; any extension request is reviewed by the support team.
